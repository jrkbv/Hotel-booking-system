


Этот проект представляет собой консольную систему управления бронированиями отеля на Python с объектно‑ориентированным дизайном и UML‑диаграммой классов для документации архитектуры.

## Общее описание

Приложение позволяет управлять номерами, гостями и бронированиями через текстовое меню. Поддерживается регистрация гостей, добавление номеров, создание бронирований, заселение и выселение, а также сохранение всех данных в JSON‑файл между запусками программы.

## Архитектура

Дизайн следует принципам ООП и описан UML‑диаграммой классов (hotel.puml и экспортированное изображение).

- Класс Hotel является фасадом и управляет коллекциями объектов Room, Guest и Booking, храня их во внутренних словарях по идентификаторам и номерам комнат.
- Room, Guest и Booking — доменные сущности, реализованные как @dataclass с типизированными полями и минимальной логикой.
- Перечисления RoomStatus и BookingStatus задают допустимые состояния номеров и бронирований, повышая читаемость и безопасность типов.
- Исключения RoomNotFoundError и GuestNotFoundError, наследующиеся от ValueError, дают более понятные ошибки при отсутствии нужных объектов.

На UML‑диаграмме показаны следующие связи:

- Hotel агрегирует несколько комнат, гостей и бронирований (композиция через словари).
- Booking всегда связан ровно с одним Guest и одним Room, что отражает связи «гость делает бронирование» и «номер забронирован».
- У Room и Booking есть поля‑статусы с типами RoomStatus и BookingStatus, что отображено как ассоциации «status».

## Основные возможности

Ключевые операции класса Hotel:

- Управление номерами: add_room, delete_room, get_room, list_rooms.
- Управление гостями: register_guest, delete_guest, get_guest, list_guests.
- Работа с бронированиями: create_booking, cancel_booking, list_bookings, check_in, check_out, при этом приватный метод _check_room_available не допускает пересечения дат для одного номера.
- Сохранение данных: методы to_dict и from_dict преобразуют состояние отеля в словари и обратно, после чего оно записывается в hotel_data.json.

Класс Booking в __post_init__ проверяет корректность дат и содержит метод overlaps для проверки пересечения интервалов бронирования.

## Консольный интерфейс

Скрипт реализует меню‑ориентированный CLI через функцию run():

- При старте загружает данные через load_hotel() из hotel_data.json, либо создаёт новый объект Hotel, если файл отсутствует.
- Показывает нумерованное меню для всех операций (добавить номер, показать номера, зарегистрировать гостя, создать бронирование, отменить, заселить, выселить, удалить номер/гостя).
- Читает даты в формате YYYY-MM-DD с помощью parse_date и после каждой операции, изменяющей данные, автоматически вызывает save_hotel для сохранения состояния.
